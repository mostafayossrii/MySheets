# Release Notes

## 1.0.0 — 2026-09-29

**MySheets 1.0.0** — first public release.

- Batch-export sheets and views to **PDF, DWG, DXF, DWF, DGN, IFC, NWC and gbXML** in a single run
- One naming rule for every file — sheet number, name, revision, discipline, scale, date, or any Revit parameter
- Review step before writing; existing files are skipped and reported, never silently overwritten
- Optional external image binding for exported DWGs (uses your installed AutoCAD)
- Supports **Revit 2020–2027** with a single unified installer
- **7-day free trial**, then offline machine-bound activation
